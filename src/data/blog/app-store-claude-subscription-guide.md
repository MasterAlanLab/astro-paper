## 一、 环境准备

开始之前，需要先准备一台苹果手机。

**1. 苹果手机（必备）**
如果你手里没有苹果手机，可以去闲鱼买一台二手的来使用。目前能够安装 Claude App 的最便宜的苹果手机应该是 iPhone SE 第一代，大概 300 块钱就可以搞定。

**2. 科学上网节点**
有了苹果手机以后，还需要一个科学上网的节点，建议使用美国、日本、新加坡这些受支持国家的节点。

在我实测下来，即便是非常廉价的机场节点也不影响订阅成功。所以那些说订阅的时候就需要使用住宅 IP 的，感觉是有点危言耸听了。不过日常使用时防封号那又是另外的方式了，这篇教程我们只讨论注册和支付。

## 二、 注册苹果账号并转美区

要通过苹果的 App Store 订阅 Claude，我们就需要有一个美区的 App Store 账号。直接注册美区苹果账号的难度比较大，因此我们采用一种曲线救国的方式：**先注册一个国区的苹果账号，再转到美区。**

### 1. 手机端注册国区账号
注册账号时记得使用苹果手机来注册，**千万不要通过网页注册**，网页注册账号大概率会失败。

1. 打开苹果手机，来到**手机设置**，选择 **Apple 账户**。
2. 点击 **“没有 Apple 账户”**，然后选择 **“成人”**，弹出来的选择框都选择同意。
3. 输入姓名和生日，选择 **“使用电子邮件地址”**，接着选择 **“没有电子邮件地址”**。
4. 在弹出来的选项卡里，点击 **“获取 iCloud 电子邮件地址”**。
   > 如果你自己有邮箱，也可以使用自己的其他邮箱。但我们这里仅仅只是为了订阅 Claude，而且很可能会注册多个账号，索性直接注册一个 iCloud 邮箱来使用就行了。我实测下来，并不会因为你是新的邮箱、新的账号就封号。
5. 输入一个自己想要的邮箱名，点击 **“创建电子邮件地址”**。
6. 设置 Apple 账户的密码，然后输入电话号码完成验证，弹出来的条款全部选择同意。

*注：如果你的手机之前登录过其他的账户，切换时之前同步的数据会暂时消失。不过只需要等订阅完成以后，重新登录之前的账号，记录就都会恢复的。*

### 2. 免绑卡切换至美区 App Store
1. 成功登录到新的 Apple 账户以后，打开 App Store，搜索并下载 **UU 加速器**，登录一个账号。
2. 打开 UU 加速器，搜索 `App Store`，选择加速 App Store。（当然，如果你的手机上已经有其他的代理工具，可以切换到其他国家的网络，那也可以不使用 UU 加速器，直接开启代理就行。）
3. 加速以后，打开 App Store，在**账户设置**里，把 **国家/地区** 从中国大陆切换到**美国**。
   > 如果没有开启代理，切换成美国的时候必须要添加一个支付方式，而搞一个美国的支付方式是非常困难的；但开启代理以后，在支付方式的地方就可以直接选择 **“无”**。
4. **填写账单地址**：可以在网上找一个美国地址生成器，最好是选择一个免税州的地址，我平时喜欢用**蒙大拿州（Montana）**或者**特拉华州（Delaware）**的地址。
5. **填写美国手机号**：如果有自己的美国手机号，最好填一个自己能接到验证码的号码；实在没有的话，随便填一个也行，我自己在使用的时候完全没有用上过这个手机号。
6. 全部填好以后，点击右上角的提交按钮，再输入一遍账户的登录密码，这样我们的 App Store 就成功切换到了美区。

## 三、 注册 Claude 账号（100% 免 KYC）

1. 首先安装并开启自己的代理工具（建议使用美国、日本、新加坡节点）。
2. 在美区 App Store 里搜索并下载 **Claude by Anthropic**。
3. 打开 Claude App，登录的时候选择 **“使用 Apple 继续”**。
4. 提示需要获取年龄信息时，依次点击 **“继续” -> “分享年龄段” -> “继续”**。
5. 在登录设置里，选择 **“隐藏邮件地址”**，点击继续。
6. 在最底部可以看到，电子邮箱地址已经是苹果提供的隐私邮箱了。勾选同意 A➗（Anthropic）的消费者条款和使用政策，点击继续。
7. 输入名字（直接用默认的就行），点击继续。
8. 下一步是一个开关，A➗想利用我们的对话数据来训练模型。默认是打开的，**我建议关闭这个开关**，然后再点击继续。
9. 弹出选择套餐的页面后，点击最底部的 **“继续使用 Free 套餐”**。

到这里，我们就有一个注册好了的 Free 账号，同时也不会触发 KYC。

我实际测试中通过 Apple 账号注册了几十个账号，全部都是通过 Apple 登录、使用隐私邮箱注册，没有一个账号会在注册成功后就要求 KYC；相反，通过网页上注册的账号，基本每一个都会要求 KYC。

## 四、 礼品卡充值

到目前为止，我们有了一个没有触发 KYC 的 Claude 免费账号，接下来就是要想办法付费订阅 Claude Pro 了。

美区的 App Store 可以选择绑定美国的银行卡或者美区的 PayPal，但不管是美国银行卡还是美区 PayPal，想要获取都很困难。对于我们绝大多数人而言，最方便的方式就是购买**苹果美区礼品卡**。

1. 打开**支付宝**，直接搜索 **“美区礼品卡”**。
2. 选一个商家进去，选择美国苹果礼品卡下单。**记得选择 $20 的面额，不要买多，也不要买少了。**
3. 支付成功以后会显示出来一个兑换码。
4. 来到 App Store 的资料页，点击 **“兑换代码”**，输入买到的礼品卡兑换码完成兑换。
5. 兑换成功后，账户余额里就会显示 `$20.00`。

## 五、 订阅 Claude Pro 与苹果 72 小时风控申诉

现在万事俱备，只欠订阅。

1. 再次打开 Claude App，选择 `$20` 的 Pro 套餐并点击订阅。
2. **注意：新注册的苹果账号会触发苹果官方的审核，第一次支付一定会失败。**
3. 这时候记得去**提交申诉**。苹果会要求你提供购买的产品，我就直接填了一个 `Claude Pro`，然后提交。
4. 接下来就是漫长的等待。虽然苹果官方说的是最长 3 天时间处理完，但我实测了多个账号，它每一次都是严格达到 **72 小时** 以后才发邮件通知我审核通过，从来没有提前过。所以提交申诉以后，耐心等满 72 小时吧。
5. 72 小时一到，收到审核通过的邮件后，回到 Claude App 就可以正常升级到 Pro 订阅了。

### 为什么我不去尝试 Max 套餐？
据网上的信息，Max 账户现在基本上是必定触发 KYC，同时也更容易封号，我觉得完全没有必要。

Claude 的订阅额度开更高等级的套餐，仅仅只是可以使用 Fable 模型，对于每个月的额度实际上并不会增加很多。而且在 App Store 里订购 Max 套餐还需要额外多付出几十刀（苹果税溢价）。如果主要是使用 Opus 模型的话，还不如直接订购多个 Pro 套餐划算。

## 六、 以前被封号的惨痛经验

在找到这个方法以前，我把市面上常见的方式基本都踩了一遍坑：

* **买别人过好 KYC 的普号（成品号）**：不管是通过网页绑卡充值，还是通过谷歌商店订阅充值，基本都难逃一死。当然也有一个号没被封，但这成功率太低了，被封几个号才能活一个号，而且还没办法退款。所以买别人的成品号一定不是一个好方式。
* **自己网页注册 + 找人代做 KYC**：结果就是 KYC 成功的邮件和账号被封号的邮件同时到达，甚至连充钱的机会都没留给我。我网页还停留在认证成功的页面呢，下一秒就自动刷新、退出登录了。打开邮箱一看，封号邮件是同一分钟发过来的，前后相差可能也就十几秒钟——也就是说我这个账号认证成功后只存活了十几秒。
* **使用谷歌商店（Google Play）订阅**：在很久之前我也尝试过，不幸的是也全部被封号了。不过通过谷歌商店订阅的账号，我怀疑是使用方式的问题导致的被封号，而不是支付方式的问题。

但不管怎么说，目前为止我实测下来最稳定的，还是**通过苹果隐私邮箱注册 + 苹果内购支付**。如果说我只成功了一个账号，那可以说是运气；但我通过这种方式在几天时间内已经连续订阅成功三四个账号，整个过程中也没有使用什么住宅 IP，全是很普通的机房 IP 就操作了，最终全部存活到现在，没有一个账号被封。这应该能说明这种方式的可靠性了。

把我的完整操作步骤分享给大家：

1. 硬件与网络准备
必须准备一台苹果手机（没有的话去闲鱼淘一台二手的 iPhone SE 一代，300 块钱就能搞定）。节点用普通的美国、日本、新加坡机场节点就行，实测订阅阶段完全不需要住宅 IP，那些说订阅就必须上住宅 IP 的有点危言耸听了。

2. 手机端注册国区 Apple ID（切勿用网页注册）
网页端注册大概率会失败，直接在 iPhone「设置」-「Apple 账户」里点「没有 Apple 账户」注册。
邮箱直接选「没有电子邮件地址」-「获取 iCloud 电子邮件地址」免费建一个新 iCloud 邮箱就行。实测下来并不会因为你是新邮箱、新账号就封号。

3. 免绑卡转美区 App Store
登录新 Apple 账户后，去 App Store 下载一个「UU 加速器」，搜 App Store 开启加速（或者直接开你手机上的代理工具）。
加速后再进 App Store 账户设置，把地区从中国大陆改成美国。只要开了代理，支付方式那里就会出现「无」的选项，不需要绑美卡。
账单地址用生成器找一个免税州地址（我习惯用蒙大拿州或特拉华州），手机号随便填一个就能过。

4. 用苹果隐私邮箱注册 Claude（核心防 KYC 步骤）
挂好美/日/新节点，在美区 App Store 下载 Claude App。
打开后选择「使用 Apple 继续」-> 分享年龄段 -> 选择「隐藏邮件地址」（也就是使用苹果提供的隐私邮箱）-> 同意条款 -> 把「允许使用对话数据训练模型」的开关关掉 -> 底部选择继续使用 Free 套餐。
我实测用苹果隐私邮箱注册了几十个号，没有一个在注册后要求 KYC 的，而网页注册基本必出 KYC。

5. 支付宝礼品卡充值
不去折腾美卡和美区 PayPal，直接打开支付宝搜「美区礼品卡」，随便找一家店买 20 美金面额的苹果礼品卡（正好 $20，别买多也别买少）。拿到兑换码去 App Store 兑换，余额到账 $20。

6. 订阅 Pro 与苹果 72 小时风控申诉
打开 Claude App 订阅 $20 的 Pro 套餐。
注意：新注册的苹果号第一次内购一定会触发苹果官方风控导致支付失败。这时候直接去提交申诉，苹果问你购买的产品是什么，直接填「Claude Pro」提交就行。
虽然苹果说最长 3 天处理完，但我实测了多个账号，每一次都是严格卡满 72 小时才发邮件通知审核通过，从来没有提前过。耐心等满 72 小时收到邮件后，再回 App 就能正常扣款升级 Pro 了。

另外多说一句，我不建议大家去开 Max 套餐。一是因为目前网上反馈 Max 账号基本必出 KYC 且极易封号；二是开更高等级套餐仅仅是能用 Fable 模型，每月额度并不会增加太多，在 App Store 订购还要多交几十刀的差价。如果主要是用 Opus 模型，真不如直接开多个 Pro 套餐划算。
