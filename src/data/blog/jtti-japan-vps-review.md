## 活动与套餐概览

- 活动页：[JTTI 周年庆活动地址](https://www.jtti.cc/zh/activity/y2026-anniversary.html?k=H2OEEI)
- 基础配置：1 核 / 1 GB 内存 / 50 GB SSD / 200 Mbps 峰值 / 1000 GB 双向月流量
- 功能：自带快照
- 政策提醒：购买后不支持退款，未写明更换 IP / Push 支持政策，但是可以免费更换绑定邮箱

## 网络与线路

- 去程/回程：
  - 电信 163/4837
  - 移动 CMI/4837
  - 联通 4837 → SoftBank/4837
- 晚高峰延迟：联通约 60 ms，移动电信约 80 ms
- 带宽：实测可长时间跑到 ~185 Mbps

## 体验速记

- 面板/开通：开通很简单，商家是支持支付宝支付的，注册账号以后选择套餐支付即可
- 稳定性：已经用了一段时间，感觉挺稳定的，包括高峰期也挺稳定
- 解锁与合规：基本上都能解锁，唯一不足是ip段被谷歌送中了，老艾正在尝试把ip定位改回日本，等取得成果以后再来汇报。
