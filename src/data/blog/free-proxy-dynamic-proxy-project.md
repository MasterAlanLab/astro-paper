## 起源

VPNgate 是由日本国立筑波大学运营的一项学术实验项目，由全世界志愿者提供了大量的公共中继服务器

这个研究的目的是推广 “全球分布式公共 VPN 中继服务器” 的知识

在他们的官网上有一个公共 VPN 中继服务器列表

不需要注册，互联网上的任何一个人都可以建立 VPN 连接到列表上的任意一台 VPN 服务器上

当然，你也可以提供自己的电脑作为一个 VPN 服务器加入到这个实验中

大概是因为这是个日本的研究项目，所以公共的 VPN 服务中日本节点占大多数

其次就是韩国节点，剩下的就是三三两两的一些其它国家

而在这些节点里面，机房IP占据多数，同时也存在不少住宅IP

我已经实际使用了一段时间，其中有一些节点使用起来效果一般

但是也不乏IP纯净度很高的住宅IP

用来作为落地 IP 的效果还不错

因为 VPNgate 支持使用 openVPN 来链接，于是我们就有了这么一种应用场景

我们现在服务器上安装好 openVPN，使用 openVPN 连接到 VPNgate 提供的节点

然后通过 http 和 socks 协议对外暴露接口

通过 v2rayN 的链式调用就可以把住宅IP作为落地IP来使用

而使用 openVPN 建立链接，并暴露出 socks 协议的接口就是我的 free-proxy 这个项目所要做的事情

## 部署和使用

这个项目在部署之前有一个前提要求

必须使用 root 用户或者通过 root 权限来执行

一般我们的 vps 都是有 root 权限的，这里我就不多赘述了

然后我们通过 ssh 登陆到服务器

```
ssh root@你的服务器IP
```

一行命令安装

```
bash <(curl -Ls https://raw.githubusercontent.com/masteralanlab/free-proxy/main/install.sh)
```

这条命令执行完毕以后，free-proxy应该就部署好了

在安装完成以后，脚本会打印出访问的路径、账号、密码

访问 `http://<你的服务器IP>:39527/xxxxxxxxxxxx/`，输入脚本打印出来的用户名和密码

我们就可以进后台了

默认情况下 socks 接口是没有开启外网访问的，如果有需要，那么可以在后台设置里打开

这个一般就看自己情况了，我因为自己的 singbox 和 free-proxy 就在同一台机器上

所以我就没有开启外网访问，我直接 127.0.0.1 就使用了
